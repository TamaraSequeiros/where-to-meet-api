# Node repository

This repository contains the backend for Where to Meet.

## Scope

- This is a separate Git repository from `../ios`.
- Do not modify the iOS app unless explicitly requested or required for the task.

## Development

- Keep the backend simple and focused.
- Prefer readable code over comments and abstractions.
- Keep comments minimal; explain why, not what.
- Avoid unrelated refactors.
- External APIs should be isolated and appropriately mocked in tests.
- Prefer meaningful behavioral and integration tests over implementation-detail tests.
